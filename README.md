# Simulação Banco

Uma aplicação de terminal desenvolvida em C# para simular operações bancárias básicas.

## Sobre o Projeto

Este projeto foi criado para praticar lógica de programação, estruturas condicionais, laços de repetição, entrada e saída de dados e manipulação de variáveis utilizando C#.

O sistema simula um banco simples diretamente no terminal, permitindo ao usuário consultar saldo, realizar depósitos e efetuar saques.

## Funcionalidades

* Consultar saldo
* Depositar dinheiro
* Sacar dinheiro
* Verificação de saldo insuficiente
* Encerrar aplicação pelo menu
* Interface simples em terminal
* Banner personalizado ASCII

## Tecnologias Utilizadas

* C#
* .NET 8
* Console Application

## Como Executar

### Executável

Baixe o arquivo:

```text
SimulacaoBanco.exe
```

Execute normalmente no Windows 10 ou Windows 11.

### Código Fonte

Clone o repositório:

```bash
git clone https://github.com/0xKxbyte/Simula-ao-Banco.git
```

Abra o projeto no:

* Visual Studio 2022
* Visual Studio Code
* JetBrains Rider

Execute:

```bash
dotnet run
```

## Estrutura do Sistema

Menu principal:

```text
1 - Ver Saldo
2 - Depositar
3 - Sacar
4 - Sair
```

Saldo inicial:

```text
R$ 1000
```
